
# FinMotion: Premium Financial Intelligence Terminal

A high-end, motion-graphics powered financial platform featuring live global market tracking, AI-driven algorithmic analysis, and cinematic data visualizations.

## 🚀 Quick Start (Local Development)

To run this project on your local machine:

### 1. Prerequisites
- **Node.js** (v18 or higher)
- **npm** or **yarn**

### 2. Setup
Create a new directory and initialize a Vite project (recommended for fastest setup with this structure):
```bash
npm create vite@latest finmotion -- --template react-ts
cd finmotion
```

### 3. Install Dependencies
```bash
npm install three @react-three/fiber @react-three/drei @react-three/postprocessing gsap framer-motion @google/genai recharts react-router-dom
```

### 4. Configure Environment
Create a `.env` file in the root and add your Gemini API Key:
```env
VITE_GEMINI_API_KEY=your_api_key_here
```

### 5. Start Development Server
```bash
npm run dev
```
Your terminal will show a link (usually `http://localhost:5173`) where you can preview the app.

## 🏗️ Project Structure
- `components/3D/`: Immersive WebGL scene components.
- `services/`: API integration for Gemini and Market data.
- `types.ts`: TypeScript interfaces for the entire app.
- `App.tsx`: Routing and main application flow.

## 🛠️ Key Features
- **Cinematic Landing Page**: Scroll-driven 3D universe powered by Three.js.
- **AI Analysis**: Real-time technical signals generated by Gemini 3 Pro.
- **Global Tickers**: Real-time simulation of NASDAQ, NIFTY, ASX, and more.
- **Modern Dashboard**: Glassmorphic UI with responsive charts.

## 🔐 Security Note
In production, ensure you proxy Gemini API calls through a secure backend to protect your API key.
